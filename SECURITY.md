# Security Policy

RAMScope is for authorized defensive memory forensics. The current supported line is `0.4.x`; other versions may not receive fixes.

Do not submit real memory dumps, malware samples, credentials, unredacted IOCs, case output, or sensitive incident data in public issues or pull requests.

For a suspected vulnerability, contact the maintainers privately through the GitHub security advisory workflow. Include the affected version, a minimal reproduction that contains no private evidence, and the potential impact. Please allow time for coordinated triage before public disclosure.
